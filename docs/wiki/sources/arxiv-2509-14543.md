# arXiv 2509.14543 — LLMs struggle to imitate implicit writing styles

**Link**: https://arxiv.org/html/2509.14543v1
**Type**: empirical paper

## Takeaways

- LLMs imitate explicit, nameable style features far better than implicit ones
  (the function-word/rhythm fingerprints that most distinguish a voice).
- Motivates making implicit features *explicit* in a structured profile.
