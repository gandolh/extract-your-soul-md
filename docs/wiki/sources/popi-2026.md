# POPI (2026) — Personalizing LLMs via Natural Language Preference Inference

**Link**: https://arxiv.org/abs/2510.17881 (WWW 2026)

## Takeaways

- A natural-language preference summary, inferred once, is **generator-
  transferable** — reusable across different frozen LLMs including black-box
  commercial APIs.
- Explicitly addresses "context rot": dumping verbose user history into context
  degrades performance; a distilled summary does not.
- A direct architectural blueprint for a portable voice profile.
