# Individualized Cognitive Simulation in LLMs (2025)

**Link**: https://arxiv.org/abs/2510.20252

## Takeaways

- Combining conceptual features (themes/idea maps) with linguistic features
  beats static profile-based cues (biographical summaries).
- LLMs mimic linguistic *style* better than narrative *structure* — they
  replicate surface patterns but fail at plot/cognitive construction.
